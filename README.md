# RandomFileGenerator
Une application permettant de généré des fichiers aléatoirement. Fait par AxelGamerProgrammer (Alias AxelGamer200)

# Comment le lancer
Lancer le fichier launcher.py et sélectionner votre app. Modifier settings.json pour le working path.

# Changelog

## V3 - The File Update

**Interface**
- Ajout de la possibilité d'ajouter un contenu pour les fichiers
- Ajout de la possibilité de généré des fichiers avec un volume défini
- Ajout de la possibilité d'avoir nos propres dictionnaires et sélectionnable via l'interface
- Ajout du dictionnaire d'anglais

**Helper**
- Ajout de la commande count qui permet de compter des fichiers via l'extension
- -> Syntaxe: count [ext]
- Amélioration de la commande delall qui permet de supprimer tout les fichiers avec une extension définit ou tout supprimer en laissant vide
- -> Syntaxe: delall [ext] / delall

**Settings**
- **Ajout d'une interface graphique pour les paramètres
- Ajout du paramètre "additional_words" permettant d'avoir des mots supplémentaire + celle du dictionnaire sélectionné

**Launcher**
- Ajout de la possibilité de lancer l'application de settings via le numéro 3
