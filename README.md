# RandomFileGenerator
Une application permettant de généré des fichiers aléatoirement. Fait par AxelGamerProgrammer (Alias AxelGamer200)

# Comment le lancer
Lancer le fichier launcher.py et vous pourriez sélectionner l'app via les nombres. Modifier settings.json pour le working path.
