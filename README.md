# RandomFileGenerator
Une application permettant de généré des fichiers aléatoirement. Fait par AxelGamerProgrammer (Alias AxelGamer200)

# Comment le lancer
Lancer le fichier launcher.py qui se situe dans le dossier lib et sélectionner les apps via le curseur bas ou haut. Lancer l'app settings pour modifier des paramètres dont le working path.
